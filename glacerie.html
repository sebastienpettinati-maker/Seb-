Comment sont calculés ces prix ? Prix indicatifs pré-remplis : modifiez-les selon vos fournisseurs, ils sont enregistrés sur cet appareil et réutilisés pour toutes vos recettes. Le poids du pot correspond au poids de mix : le foisonnement ajoute du volume, pas du poids — un pot de 120 g contient bien 120 g de mix. Si un contenant est vendu avec la glace, son prix d'achat entre dans le prix de vente avec un coefficient de 2 (contre le coefficient choisi, en général 5, pour les matières premières) : prix conseillé = coût matières du pot × coefficient + prix du contenant × 2.

📷 Lots fournisseurs

Photographiez l'étiquette de chaque produit utilisé : le numéro de lot est extrait de la photo (vous pouvez aussi le saisir à la main) puis reporté sur la feuille de fabrication, à imprimer et archiver.

Que contient la feuille de fabrication ? La feuille reprend la production du jour (produit, date, n° de lot, DDM, pots, coût), la recette complète avec le numéro de lot fournisseur de chaque ingrédient et, si la case est cochée, les photos des étiquettes en annexe. L'extraction du numéro depuis la photo nécessite une connexion internet (au moins la première fois) ; la saisie à la main fonctionne toujours, même hors connexion.

🏷️ Traçabilité & étiquettes DLC

Une fois la production sortie de turbine, indiquez la date, le lot et le nombre de pots remplis, puis imprimez la fiche de traçabilité et les étiquettes — calées sur des planches autocollantes A4 de 18 étiquettes de 100 × 30 mm (2 × 9).

Que contiennent la fiche et les étiquettes ? La fiche de traçabilité reprend la production (date, lot, DDM, pots), le coût du lot et la liste des ingrédients mis en œuvre avec leur lot fournisseur. Chaque étiquette de 100 × 30 mm porte le nom du produit en élégantes capitales, une illustration noir et blanc assortie au parfum en fond — choisie d'après le nom de la recette (« fraise » → une fraise, « pistache » → une pistache…), sinon d'après les ingrédients —, la liste des ingrédients par ordre décroissant avec les allergènes en gras, le n° de lot, le poids net, la date de production et la DDM. À l'impression : échelle 100 % (taille réelle), marges automatiques et en-têtes / pieds de page désactivés, pour que la grille tombe exactement sur les étiquettes prédécoupées. Sauvegarde automatique sur Google Drive

Collez une seule fois l'adresse de votre script Google (voir « Première installation » ci-dessous) : les fichiers recette, fiche de traçabilité et étiquettes seront envoyés automatiquement dans un dossier « Glacerie » de votre Drive à chaque export ou impression.

Première installation : créer le script Google (une seule fois, ~2 minutes)
  1. Ouvrez script.google.com (connecté à votre compte Google) et cliquez sur Nouveau projet.
  2. Effacez le contenu et collez le code ci-dessous, puis enregistrez (💾).
  3. Cliquez sur Déployer → Nouveau déploiement → ⚙ Application Web ; « Exécuter en tant que » : Moi ; « Qui a accès » : Tout le monde (indispensable) ; puis Déployer.
  4. Autorisez l'accès quand Google le demande. Si un écran « Google n'a pas validé cette application » apparaît, touchez Paramètres avancés → Accéder au projet (non sécurisé) : c'est votre script, sans risque.
  5. Copiez l'URL de l'application Web (elle se termine par /exec) et collez-la dans le champ ci-dessus, puis cliquez sur « Tester ». Astuce : en ouvrant cette adresse dans le navigateur, vous devez voir {"ok":true…} — sinon le déploiement est à refaire.
  6. Après toute modification du script, refaites Déployer → Gérer les déploiements → ✏️ → Version : Nouvelle version → Déployer (l'URL ne change pas).
function doGet() {
  return reponse({ ok: true, message: 'Script Glacerie pret' });
}
function doPost(e) {
  try {
    var d = JSON.parse(e.postData.contents);
    var it = DriveApp.getFoldersByName('Glacerie');
    var dossier = it.hasNext() ? it.next() : DriveApp.createFolder('Glacerie');
    var anciens = dossier.getFilesByName(d.nom);
    while (anciens.hasNext()) anciens.next().setTrashed(true);
    dossier.createFile(d.nom, d.contenu, 'text/html');
    return reponse({ ok: true });
  } catch (err) {
    return reponse({ ok: false, erreur: String(err) });
  }
}
function reponse(o) {
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

Le script tourne sur votre compte Google et écrit uniquement dans votre Drive : personne d'autre n'y a accès. Si un fichier du même nom existe déjà (même jour, même recette), il est remplacé par la dernière version.

Dans la fenêtre d'impression, choisissez « Enregistrer au format PDF » comme destination.
