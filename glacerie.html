🏷️ Traçabilité & étiquettes DLC

Une fois la production sortie de turbine, indiquez la date, le lot et le nombre de pots remplis, puis imprimez la fiche de traçabilité et la planche d'étiquettes à coller sur les pots.

Que contiennent la fiche et les étiquettes ? La fiche de traçabilité reprend la production (date, lot, DDM, pots), le coût du lot et la liste des ingrédients mis en œuvre avec une colonne « lot fournisseur » à compléter. Chaque étiquette porte la liste des ingrédients par ordre décroissant avec les allergènes en gras, le poids net, le n° de lot, la date de production et la date de durabilité minimale.

Sauvegarde automatique sur Google Drive

Collez une seule fois l'adresse de votre script Google (voir « Première installation » ci-dessous) : les fichiers recette, fiche de traçabilité et étiquettes seront envoyés automatiquement dans un dossier « Glacerie » de votre Drive à chaque export ou impression.

Première installation : créer le script Google (une seule fois, ~2 minutes)
  1. Ouvrez script.google.com (connecté à votre compte Google) et cliquez sur Nouveau projet.
  2. Effacez le contenu et collez le code ci-dessous, puis enregistrez (💾).
  3. Cliquez sur Déployer → Nouveau déploiement → ⚙ Application Web ; « Exécuter en tant que » : Moi ; « Qui a accès » : Tout le monde ; puis Déployer et autorisez l'accès.
  4. Copiez l'URL de l'application Web (elle se termine par /exec) et collez-la dans le champ ci-dessus, puis cliquez sur « Tester ».
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var it = DriveApp.getFoldersByName('Glacerie');
  var dossier = it.hasNext() ? it.next() : DriveApp.createFolder('Glacerie');
  var anciens = dossier.getFilesByName(d.nom);
  while (anciens.hasNext()) anciens.next().setTrashed(true);
  dossier.createFile(d.nom, d.contenu, 'text/html');
  return ContentService.createTextOutput('{"ok":true}')
    .setMimeType(ContentService.MimeType.JSON);
}

Le script tourne sur votre compte Google et écrit uniquement dans votre Drive : personne d'autre n'y a accès. Si un fichier du même nom existe déjà (même jour, même recette), il est remplacé par la dernière version.

Dans la fenêtre d'impression, choisissez « Enregistrer au format PDF » comme destination.
