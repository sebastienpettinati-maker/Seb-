En arrivant le matin, touchez chaque case : prenez la photo de l'étiquette du produit correspondant ou choisissez-la dans votre galerie — le beurre dans la case Beurre, la crème dans la case Crème. Comment ça marche ? En touchant une case (ou le bouton photo), votre téléphone propose de prendre la photo ou de la choisir dans la galerie. L'étiquette est ensuite lue par un service de reconnaissance externe (OCR.space, très fiable — seule la photo de l'étiquette lui est envoyée, rien d'autre) : le produit est reconnu, le numéro de lot et la DLC sont extraits et pré-remplis. Sans connexion, une lecture locale prend le relais. Tout reste corrigeable à la main et « 🔍 Relire » relance la lecture.

Si la lecture répond « service saturé », créez une clé gratuite sur ocr.space (25 000 lectures/mois) et collez-la ici : elle reste sur cet appareil.

☁️ Enregistrer sur Google Drive

Depuis le téléphone, le plus simple : dans la liste ci-dessus, touchez « 📤 Enregistrer sur Drive » sur une journée — le menu de partage du téléphone s'ouvre, choisissez Drive et le dossier voulu. Aucune installation.

Automatique chaque jour (facultatif) : pour que la feuille parte toute seule à chaque production, collez ci-dessous l'adresse d'un petit script Google. Cette installation-là se fait une fois sur un ordinateur (voir « Première installation »).

Première installation (5 min, une seule fois)
  1. Sur un ordinateur, allez sur script.google.com et créez un Nouveau projet.
  2. Effacez le contenu et collez le code fourni ci-dessous (bouton « Copier le code du script »).
  3. Cliquez sur Déployer ▸ Nouveau déploiement, type Application Web, « Exécuter en tant que : moi », « Accès : tout le monde », puis Déployer et autorisez.
  4. Copiez l'URL de l'application Web (elle se termine par /exec), collez-la dans le champ ci-dessus, puis touchez « Tester la connexion ».
